# C'est quoi TermMezz ? 

TermMezz est un programme en python qui utilise l'api de Gemini pour répondre à vos questions à la place d'aller sur le site de Gemini.

# Comment télécharger TermMezz ?

Pour télécharger le projet afin d'utiliser TermMezz, il vous faudra copier cette commande : 

```bash
winget install --id Git.Git -e --source winget
```

ça installera Git qui vous permettra d'avoir git pour installer le projet, ensuite vous allez faire cette commande : 

```bash
git clone https://github.com/mezzdev/TermMezz
```

Une fois que le projet sera installé, il faudra ouvrir un terminal ( cmd de préférence ) et taper la commande suivante :

```bash
pip install google-genai colorama
```

Puis vous allez télécharger le fichier Main.py et vous allez dans le terminal ( toujours cmd ) aller dans l'endroit où se trouve le fichier Main.py et taper la commande suivante :

```bash
python Main.py
```

Et vous allez rentrer votre clé d'API de Gemini et vous pourrez commencer à utiliser TermMezz.
